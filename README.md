# 脉脉招聘自动化技能

## 简介

专门用于脉脉企业招聘端 (`maimai.cn/ent`) 的自动化招聘技能，支持候选人搜索、智能筛选、个性化触达和执行报告。

## 核心功能

- 🔍 **轮次矩阵搜索**：关键词 × 公司筛选组合，精准覆盖目标候选人
- 🎯 **双重筛选机制**：平台筛选 + 人工硬筛，层层把关
- ✍️ **个性化触达**：每条消息都包含候选人真实信息，3段式结构
- 🤝 **人机协作节奏**：首批确认 + 每5人暂停，可控可信
- 📊 **100分评分模型**：公司40分 + 学校30分 + 活跃15分 + 意愿15分

## 搜索策略

### 轮次矩阵设计
```
搜索轮次 = 关键词 × 公司筛选组合

示例：
- 轮次1：算法 × 一线互联网大厂
- 轮次2：算法 × AI独角兽
- 轮次3：LLM × 985学校
```

### 双重筛选
**第一层：平台筛选**
- 学校、公司、城市、学历、年限

**第二层：人工硬筛**
- 按钮状态检查（`沟通` vs `立即沟通`）
- 专业检查（计算机相关）
- 去重检查（历史 + 本轮）

## 个性化触达

### 3段式消息结构
1. **切入点**：引用候选人的公司/方向/技术标签
2. **机会点**：说明团队当前业务与技术挑战
3. **邀请句**：自然发出低压力沟通邀请

### 约束条件
- 必须包含候选人真实信息
- 100-180字（严格<300字）
- 不用模板、不群发、不夸张
- 语气平等、直接、自然

## 消息示例

### 大厂在职
> 看到你在字节做推荐算法方向已经两年了，经验很扎实。我们这边做工业智能场景的算法落地，技术挑战和业务反馈闭环都很直接，如果你愿意看看新的场景，可以聊聊。

### AI 独角兽在职
> 看到你在智谱做大模型相关工作，这段经历很有含金量。我们正在推进 LLM 在垂直领域的落地，模型效果会直接连接业务结果，想邀请你了解下具体方向。

## 执行质量标准

1. **全程幂等**：同一候选人同一天不重复触达
2. **过程可复盘**：每轮都能回溯筛选条件和结果
3. **消息可解释**：每条都能对应候选人背景依据
4. **退出可恢复**：中断后可基于缓存继续下一轮

## 与 BOSS 直聘对比

| 特性 | 脉脉招聘 | BOSS 直聘 |
|------|---------|----------|
| 搜索方式 | 主动关键词搜索 | 平台推荐候选人 |
| 公司筛选 | AND逻辑（需分轮） | OR逻辑（一次多选） |
| 消息风格 | 个性化职场社交 | 标准招聘话术 |
| 活跃度信息 | 丰富（今日/周/月） | 较少 |
| 平台定位 | 职场社交 | 招聘工具 |

## 使用场景

适用于在脉脉平台上主动搜索候选人、精准触达和建立职场联系。
