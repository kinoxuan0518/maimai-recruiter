# Platform UI Reference (2026-02)

以下内容用于页面控件定位与异常时回退判断。

## 1) 毕业学校筛选器

- 预设：`985` / `211` / `QS排名Top500` / `海外Top500`
- 支持搜索具体学校名

## 2) 就职公司筛选器

- 预设分组：`BAT` / `TMDJ` / `一线互联网公司` / `二线互联网公司`
- 支持搜索公司名（模糊匹配）
- 支持勾选：`正任职` / `曾任职`

## 3) 关键词搜索

- 支持“所有关键词（AND）”和“任一关键词（OR）”
- 支持双引号精确匹配（如：`"算法工程师"`）

## 4) 排序方式

- 综合排序
- 活跃优先
- 匹配度优先

## 5) 左侧智能筛选

- 公开求职意向
- 近期有动向
- 有附件简历
- 有过意向
- 企业号互动
- 招聘动态：近期未查看 / 近期未沟通

## 6) 搜索结果按钮状态

- `立即沟通`（蓝色）= 未触达，可执行
- `沟通`（描边）= 已触达，应跳过

## 7) 触达弹窗关键字段

弹窗标题：`招聘立即沟通`

关键字段：

- 候选人信息区域（姓名/公司/职位）
- `请选择加入职位` 下拉框（必选）
- 消息编辑区（300 字上限）
- `附带职位` 开关
- `对方在线时智能索要简历或电话` 开关
- `发送后继续沟通` / `发送后留在此页` 按钮

## 8) 常见异常与定位策略

- 结构变化：先截图，再按文本锚点重定位。
- 弹窗缺失：等待 3 秒后重试，最多 3 次。
- 公司名无结果：尝试简称、全称、英文名、历史名称。
